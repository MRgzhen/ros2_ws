## 第 1 层：OpenCV 传统视觉（步骤 1–4，1–2 天）

### 步骤 1：图像订阅节点（练"管道"）

新建包 `vision_learn`（rclpy），写 `image_sub.py`：
- 话题名做成 ROS 参数 `image_topic`，默认填实际相机话题；
- `cv_bridge` 转 numpy，`cv2.imshow` 实时显示 + 按 s 存图到 `~/data/vision_learn/`；
- 顺手存 30 张不同角度的图（步骤 9 训 YOLO 用）。

**完成标准：** 窗口实时显示画面 ≈5Hz；能存图。

### 步骤 2：HSV 分割 + 轮廓检测（练"检测"，半天出效果）

- `cv2.cvtColor → cv2.inRange`（先测红色圆柱或可乐罐，`cv2.createTrackbar`
  调 H/S/V 上下限）；
- `findContours` + `minAreaRect` → 检测框 + 质心，画在 imshow 窗口上。

**完成标准：** 目标物在画面内移动时框稳定跟随；背景/桌面不误检。

### 步骤 3：solvePnP 求 6D 位姿（练"位姿"——A3 同款方法）

- 订阅 `/camera_head/depth/camera_info` 拿内参（fx/fy/cx/cy；仿真 RGB 与深度同内参，可直接用）；
- 已知物体尺寸（Gazebo 里查 model.sdf 的 size，比如 mustard 瓶高/宽），
  取检测框 4 角做物体角点近似 → `cv2.solvePnP` → rvec/tvec → 旋转矩阵+平移；
- ⚠️ 仿真的 RGB 与 depth 天然对齐，真机要 align——概念知道即可。

**完成标准：** 输出的 tvec 与 Gazebo 里物体实际位置（左侧实体树点击看 pose）误差 <3cm。

### 步骤 4：位姿进 TF（练"坐标变换"——手眼标定预习）

- 用 `tf2_ros.TransformBroadcaster` 把位姿发成 `object_frame`（注意
  optical frame 的 z 朝前惯例与 base_link 的转换，用 `tf_transformations`）；
- RViz 里看 `object_frame` 坐标轴是否贴在物体上、随物移动。

**完成标准：** RViz 中坐标轴贴合物体（点云/模型显示下目视重合），移动物体后跟随。

## 第 2 层：点云几何管线（步骤 5–7，2–3 天，对齐本项目视觉方案.md）

### 步骤 5：桌面分割 + 聚类（复刻方案前半段）

- `pip install open3d`（装在 venv 或 --user，别污染系统）；
- 订阅 PointCloud2 → 转 open3d 点云；
- 直通滤波（裁相机视野）→ **RANSAC 平面分割去桌面** → **欧式聚类分物体**；
- 每个聚类输出点数/质心/包围盒，和步骤 2 的检测框互相验证（2D 框 vs 3D 聚类）。

**完成标准：** 桌上 N 个物体分出 N 个聚类，质心与 solvePnP 结果差 <2cm。

### 步骤 6：ICP 精配准（A3 把手位姿的主案预演）

- mustard 的 mesh 在 `mycobot_gazebo/models/mustard/meshes/mustard.dae`，
  转 `.ply`（assimp 或 Blender，或用 trimesh：`trimesh.load('...dae').export('mustard.ply')`）；
- 用步骤 5 聚类出的点云（或步骤 2 框内 ROI 点云）做 ICP 初对齐（质心对齐+主轴）→
  `open3d.pipelines.registration.registration_icp` 精配准；
- 输出精细 6D 位姿，与步骤 3 的 solvePnP **互校**（差 >3cm 告警）。

**完成标准：** ICP 收敛（fitness >0.8）；两法位姿互差 <2cm/5°——
**这个双源互校模式就是 A3 的 ICP+QR 互校设计，原样搬。**

### 步骤 7：位姿喂给 MoveIt（对接 README 阶段六）

- 位姿发布成 `geometry_msgs/PoseStamped`（frame 用 base_link）；
- 复用项目里的 MoveIt 流程：加碰撞物体/设定目标位姿，
  跑一次"检测到 mustard → 规划到它上方"。

**完成标准：** RViz 里规划终点位于物体正上方 <2cm 偏差（抓不抓得住先不管）。

## 第 3 层：进阶（可选，时间富余再做）

- **步骤 8 ArUco**：物体上贴 ArUco（Gazebo 里给模型贴纹理或真机贴纸），
  `pip install pupil-apriltags` 检测 → 直接 6D，与步骤 3/6 对比精度——
  这条就是 A3 的"QR 保底"路线。
- **步骤 9 YOLO**：用步骤 1 存的图 + 多角度补拍，标注 3–5 类（mustard/coke/box/…），
  ultralytics 训 yolov8n（CPU 挂夜或云 GPU），替换步骤 2 的 HSV。
- **步骤 10 全链**：检测 → 位姿 → MoveIt 抓取 → 复位，跑通"看到→抓起"。
